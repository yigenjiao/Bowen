定位

模型做出来只是一半，能直接放进项目才算交付。

甲方要的是拿到手就能用的资产。我按需求出模型、道具和地编，同时把命名、贴图绑定、UV 和导出格式一起整理好，少走来回返工。

常见问题

  • 导出后贴图丢失、错位或发黑
  • 命名混乱，找不到对应的资源
  • 导进引擎比例不对、骨骼散架
  • 风格和原项目对不上
  • 结论：来回返工，拖慢进度

我的做法

  • 按需求和参考定好风格、面数与贴图规格
  • 贴图、材质和命名统一整理
  • 导出前逐项检查 UV、法线和蒙皮
  • 交付标准 GLB 与贴图集，附节点结构表
  • 结论：导入引擎就能用

TOOL · GLB 体检台

拖进一个 GLB，
十几项导出坑一次查完

预览模型，同时直接读 glTF 原始字节做体检。每个问题都写了成因和修复写法，可以一键定位到出问题的网格，也可以导出 Markdown 报告附在交付里。另有法线、UV 棋盘格、顶点色和骨骼权重视图。

打开体检台 → 看它怎么抓坏样本
  • 坑 1bindposes 行 / 列主序写反
  • 坑 2accessor 按 float64 落盘
  • 坑 3COLOR_0 乘贴图染色 / 发黑
  • 坑 4GLB 的 buffer 带 uri
  • 几何索引越界 · 法线未归一 · min/max
  • 蒙皮权重和 · 骨骼索引越界
  • 场景零缩放节点 · 贴图格式与尺寸
